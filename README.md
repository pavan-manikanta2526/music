# SONIC — Music Streaming Webpage

A modern, dark-mode music streaming interface built using **pure HTML5 and CSS3** (with zero JavaScript, frameworks, or external libraries).

🔗 **Live Demo:** [https://magical-truffle-05fe7e.netlify.app](https://magical-truffle-05fe7e.netlify.app)

---

## Features & Sections

- **App Layout & Navigation:** Fixed left sidebar with smooth anchor links across sections (*Home*, *Recently Played*, *Popular Tracks*, *Top Artists*, *Albums*, *Playlists*), paired with a sticky top search bar and a pure-CSS mobile drawer menu.
- **Featured Spotlight Banner:** Highlights the *Album of the Week* (*Midnight Frequencies* by *Nova Pulse*) with quick-action controls.
- **Recently Played Songs:** Compact horizontal cards with hover play badges for quick access to recent tracks (*Neon Horizon*, *Velvet Rain*, *Golden Hour Echoes*, *Starlight Drift*).
- **Popular Tracks Chart:** Ranked top-5 global tracklist displaying track numbers, cover thumbnails, artist names, album titles, and durations.
- **Popular Artists:** Circular artist cards featuring monthly listener stats (*Elena Vance*, *Nova Pulse*, *Sora Takahashi*, *Kairo Beats*, *Maya Lin*).
- **Top Albums & Curated Playlists:** Responsive square media cards with hover animations and floating play triggers (*Late Night Lo-Fi*, *Synthwave Drive*, *Acoustic Mornings*, *High Voltage*).
- **Persistent Bottom Music Player:** Glassmorphic fixed player bar featuring pure-CSS **Play/Pause** (`▶` / `❚❚`) and **Favorite** (`♥`) toggles, progress bar, equalizer bars, and volume indicator.

---

## Tech Stack

- **HTML5** — Semantic structure and accessible form/label controls
- **CSS3** — Custom properties (design tokens), CSS Grid & Flexbox layouts, responsive breakpoints, and checkbox-driven interactive states
